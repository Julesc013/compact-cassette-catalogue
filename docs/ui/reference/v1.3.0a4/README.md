# v1.3.0a4 visual discovery record

Alpha 4 is immutable at tag `v1.3.0a4`. Its retained packages exposed layout
failures during owner testing; no Alpha 4 image or package may be replaced to
make that checkpoint appear corrected.

Native captures should be added with manifests for the exact retained package
hashes and should demonstrate at least:

- `frmMain` header overlap at a reduced width;
- tape/add-dialog static buttons moving independently of scaled content;
- list-window filter/action/result geometry failures; and
- any x64 process-without-window observation tied to `UI-START-001`.

Until those native images are retained, the source geometry, owner report, and
Alpha 4 package hashes are the discovery evidence. This directory deliberately
contains no fabricated screenshot.
