# C3 1.x visual references

These directories freeze the visual inheritance and review evidence for the
Alpha 5 layout migration.

| Reference | Purpose |
| --- | --- |
| [`v1.2.0b1/`](v1.2.0b1/) | Historical repository visual inheritance oracle |
| [`v1.3.0a4/`](v1.3.0a4/) | Immutable owner-test discovery checkpoint |
| [`v1.3.0a5/`](v1.3.0a5/) | Future approved Alpha 5 native capture set |

Image files are immutable evidence. Add a new named capture rather than
overwriting an existing file. Every capture manifest records package SHA-256,
source commit, lane, operating-system build/theme, effective DPI, system font,
work area, form/state, capture method, operator, and date.

`DrawToBitmap` atlases belong with automated diagnostics, not this native
visual-review authority.
