The derived minimum environment IDs are `xp-sp3-x86-net40`,
`windows-7-sp1-x64-net48`, and `windows-11-21h2-arm64-net481`. The operator

retained entry manifest, an exact extraction, and both expected
published/candidate SHA-256 values. Do not pass `-TargetEnvironmentId`; the
verifier derives it from WMI, native architecture, and the Full Framework
registry key. Attach its generated evidence file. The XP execution must use the
actual Windows PowerShell 2-tested scripts.

## Binary and process proof

- [ ] Transferred ZIP SHA-256 matches the retained candidate manifest.
- [ ] Package-entry manifest SHA-256 matches retained release evidence.
- [ ] Extracted payload contains exactly the five allow-listed regular files;
  every length and SHA-256 matches the authenticated entry manifest.
- [ ] Only after entry verification, `BUILD.txt` source/lock/lane/EXE/config
  values match the authenticated package contract.
- [ ] `.exe.config` remained beside the EXE.
- [ ] Native target architecture matches the lane.
- [ ] OS version/build, service pack, and Full Framework install/release meet
  the lane's closed mechanical minimum.
- [ ] ARM64 only: executable is `AA64`, host is ARM64, and no x64/AnyCPU/ARM64EC
  fallback or emulated process was used.
- [ ] Launch creates the main window and ordinary close exits cleanly.
- [ ] No unexpected DLL, installer, updater, service, task, or administrator
  requirement appears.

## Lane-specific proof

- x86/net40: repeat on .NET Framework 4.0 Full and the final 4.0.3 update state;
  confirm unavailable modern TLS/browser integration does not crash C3.
- x64/net48: record fully serviced Windows 7 SP1 state, and attach later-x64
  Windows smoke results without representing Windows 7 as Microsoft-supported.
- ARM64/net481: record separately installed .NET Framework 4.8.1; inspect
  WinForms fonts, icons, dialogs, DPI/rendering, settings, XML exchange, and
  architecture-sensitive dependencies or P/Invoke.
