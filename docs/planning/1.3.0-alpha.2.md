# C3 1.3.0 Alpha 2 checkpoint

Planned tag: `v1.3.0a2`

Status: release identity projected; builder servicing and the live Alpha
production gate remain open. No Alpha 2 tag or distribution exists merely
because this plan is committed.

Alpha 2 is a retained, intentionally unpublished engineering checkpoint. It
proves the ratified three-lane build and release-control path before historical
Gate 1 and the application repair sequence begin. The owner has granted standing
authority for this deliberate Alpha operation after every gate below passes.
Public publication is not included in that authority.

## Source and evidence commits

Alpha production separates the frozen build source from retained evidence:

```text
clean pushed source commit C
        +
one external immutable lock bound to C
        -> Preparation and Candidate builds
        -> deterministic packages and smoke evidence
evidence-only descendant E
        -> retains completed human and machine qualification records
        <- annotated tag v1.3.0a2 points here
post-tag descendant P
        -> records the now-existing tag object and remote tag
        -> changes only the dedicated post-tag JSON record
```

`E` may change only the Alpha 2 validation record and other explicitly reviewed
evidence projections. It must not alter application bytes, the lane manifest,
package inputs, or the external lock. Every package records `C`; the annotated
tag records the evidence-complete checkpoint `E`.
The tag object cannot be named inside `E` without self-reference. After the tag
is created and pushed, direct child `P` records its object/target, the remote
ref, retained hashes, and unchanged publication/feed/legacy boundaries. The tag
remains immutable at `E`; `dev/1.x` advances to `P`.

## Technical entrance gate

1. Confirm no elevated Visual Studio installer process remains active.
2. Service the maintained builders to at least VS2017 `15.9.81`, VS2022
   `17.14.37`, and VS2026 `18.8.2`, or later stable servicing available at
   freeze.
3. Re-inventory exact product and installation versions.
4. Remove stale build, package, and evidence outputs under the validated
   artifact roots.
5. Confirm the exact Alpha 2 identity projection and stable-feed isolation.
6. Push the exact clean Alpha 2 source commit `C` to `origin/dev/1.x`.
7. Run the complete source-only preparation suite from `C`.

## Build and package gate

8. Rebuild all three lanes in Preparation mode and retain exact tool identities.
9. Freshly fetch `origin/dev/1.x`, verify it still equals `C`, and capture one
   immutable external Alpha/control-path lock.
10. Rebuild all three lanes in offline Candidate mode using `C` and that one
    lock.
11. Pass final source/ref/submodule/genome/lane/lock closure after the last lane.
12. Produce exactly the three `1.3.0a2` ZIPs, `SHA256SUMS.txt`, and authenticated
    entry manifests.
13. Run `build/test-source-reproducibility.ps1` with the external lock. It must
    perform two clean, path-distinct Candidate source rebuilds of all three
    lanes—not two packaging passes over retained binaries—and compare build,
    ZIP, checksum, and entry-manifest bytes with the authoritative set.
14. Run x86 and x64 builder smoke. Record ARM64 runtime as deferred, never as an
    x64-emulated pass.
15. Record the inherited recursive-close defect without waiving or repairing it
    as part of this checkpoint.

## Tag and retention gate

16. Populate `1.3.0-alpha.2-qualified.json` with
    `build/new-alpha2-qualified-record.ps1`, complete the human validation
    record, and commit exactly those two records as evidence-only commit `E`.
    Create annotated tag `v1.3.0a2` pointing to `E`, run the complete validator
    in `Tagged` mode at `E`, and push the tag only after that pass.
17. Populate `release/validation/1.3.0-alpha.2-post-tag.json` with
    `build/new-alpha2-post-tag-record.ps1`, commit direct child `P`, push
    `dev/1.x`, and run the validator in `PostTag` mode. Retain the exact
    ZIPs, checksums, external lock, provider receipt, build logs, package-entry
    manifests, source-reproducibility record, and validation evidence.

The annotated tag message must contain all of these exact fragments:

```text
C3 1.3.0 Alpha 2
unpublished engineering preview
Historical Gate 1: deferred
Runtime repairs: deferred
Native ARM64 execution: deferred
Target-OS qualification: deferred
Public publication: not authorized
```

## Required non-claims

Alpha 2 does not:

- qualify a minimum operating system;
- complete historical Gate 1;
- implement a runtime repair;
- advance `legacy/1.x`;
- change the public `VERSION` feed;
- authorize a public GitHub Alpha release; or
- authorize any Beta tag or Beta-labelled artifact.

Explicit human approval is required before even retaining a package whose name
contains `1.3.0b1` or creating/moving `v1.3.0b1`.

## Exit

Alpha 2 exits only when all 17 operations pass. The retained records name the
exact source, evidence commit `E`, tag object, tag target, remote tag identity,
external-lock SHA-256,
three package hashes, entry-manifest hashes, builder versions, smoke results,
and every deferral; repository history proves that post-tag commit `P` is the
direct child of `E` and changes only the post-tag record. Until then, the
stage-aware repository projection is preparation rather than an Alpha
distribution claim.
