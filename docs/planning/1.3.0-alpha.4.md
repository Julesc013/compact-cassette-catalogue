# C3 1.3.0 Alpha 4 owner-test checkpoint

Planned tag: `v1.3.0a4`

Alpha 4 is the immutable, intentionally unpublished owner-test checkpoint that
exposed the need for Alpha 5. Alpha 3 remains deliberately untagged and
superseded; the retained Beta-labelled Candidate NO-GO evidence remains
immutable historical input. Alpha 4 does not waive the missing historical or
native target rows.

Owner testing found overlapping controls, broken resize relationships, and
runtime-created widgets moving independently under the property-only layout
policy. The Alpha 4 source/build/package result remains truthful and its tag
and bytes never move. Its presentation mechanism is superseded by the
[Alpha 5 Legacy Layout Stabilization plan](1.3.0-alpha.5.md).

## Technical gate

1. Freeze and push one clean `dev/1.x` source commit `C`.
2. Pass lane, genome, compatibility, XML, offline, accessibility,
   documentation, PowerShell 2, and all 130 source regressions.
3. Fetch and bind `origin/dev/1.x`; capture one immutable external toolchain
   lock for `C`, then permit Candidate-mode builds to run offline.
4. Rebuild all three application lanes and all six setup/uninstall executables.
5. Verify exact PE machine, framework, configuration, metadata, payload,
   package-entry, source, and lock identity.
6. Assemble exactly six ZIPs and one six-line `SHA256SUMS.txt`.
7. Reproduce the complete build/package/evidence set from two clean,
   path-distinct source checkouts.
8. Run x86 and x64 builder smoke. Record native ARM64 execution and exact
   minimum-OS/setup qualification as owner/target-machine work, not builder
   proof.
9. Commit one evidence-only child `E` of `C`, create annotated `v1.3.0a4` at
   `E`, push the tag, and retain the unchanged bytes for owner testing.

## Test and authority boundary

The Alpha tag message and retained record must say that owner acceptance,
historical Gate 1, and exact XP/Windows 7/native ARM64 execution remain pending
unless separately evidenced. The tag and ZIPs are authorized local test
artifacts. A public GitHub Alpha release is not implied.

No `v1.3.0b1` tag, Beta-labelled byte, public Beta prerelease, `master` change,
`legacy/1.x` movement, `VERSION` feed change, or stable operation follows from
Alpha 4. Alpha 5 source, geometry, native visual, accessibility, performance,
startup, package, and owner-test gates now precede any Beta decision.
