# C3 1.3.0 Beta 1 plan

Planned tag: `v1.3.0b1`

Beta 1 is the first runtime-complete 1.3 candidate. It is not created on a date;
it is created when the work and evidence below are complete.

## Entry gate

- reproduce authoritative VS2015/MSBuild 14 x86 and x64/net40 baseline builds;
- rerun the recorded `v1.2.0b1` workflows in disposable environments;
- retain private representative catalogues outside Git;
- record fresh baseline screenshots/control evidence; and
- execute the `v1.1.2`/`v1.2.0b1` canonical-catalogue exchange.

## Runtime commit sequence

Each numbered outcome is a separate focused commit unless its test-only
predecessor is split out first.

1. pending tape-edit resolution before close/open/new/scroll;
2. nonrecursive close confirmation and cancellation;
3. Save As cancellation and single Open-dialog flow;
4. temporary-state catalogue loading and hostile-input limits;
5. same-directory transactional save, reopen verification, backup, and cleanup;
6. external-modification detection;
7. explicit named tape-field updates preserving IDs and creation dates;
8. peak/bias/calibration round-trip corrections;
9. model-notes and deck-counter one-line corrections;
10. referenced brand/model/deck deletion protection and safe brand rename;
11. row-derived counts and per-model counters;
12. maximum-based unique tape sequence allocation;
13. prevalidated atomic bulk insertion and per-copy numbering;
14. duplicate deck-choice prevention;
15. console export path fallback and nonfatal write errors;
16. historical display-name brand reference protection; and
17. settings upgrade marker, retry behaviour, and known-value normalization.

For every commit: reproduce, test, patch original files, run the focused test,
run the genome gate, update the salvage ledger, and run the full automated suite.

## Build and package completion

- install/pin the authoritative net40 compiler and supported targeting packs;
- keep one physical project/source tree;
- finalize lane-specific AppConfig/manifest metadata without feature divergence;
- add deterministic portable packaging with an exact payload allow-list;
- add PE, framework, assembly, product/stage, settings, resource, and format checks;
- prove two different clean absolute source paths yield identical ZIPs; and
- retain the qualified ZIPs and checksum manifest for possible publication.

## Automated exit gate

- complete frozen-genome comparison with reviewed allow-list entries only;
- unit/characterization coverage for every repair;
- malformed, unsupported, external-entity, oversized, and hostile XML safety;
- failed-load active-state preservation;
- transactional-save fault injection and recovery;
- historical producer and reverse-reader matrix;
- settings migration matrix;
- same source/resources and no runtime DLLs across all four lanes;
- correct binary identity and deterministic packages; and
- clean repository/document/link/generated-output checks.

## Manual exit gate

Run every workflow in the qualification matrix against exact retained packages.
Minimum OS evidence is XP SP3 x86/net40, Windows 7 SP1 x64/net40 and x64/net48,
Windows 10 22H2 x64/net481, and Windows 11 x64/net481.

## Publication decision

Beta 1 may be published as a GitHub prerelease only after the complete gate
passes and the owner accepts the retained bytes. If not published, the tag and
evidence must say intentionally unpublished. The legacy stable feed never points
to Beta 1.
