# C3 1.3.0 Alpha 5 browser command rows — 6 August 2026

Result: **PASS for the focused browser-family command-row tranche.**

Brands, Models, Decks, and Tapes retain their original action GroupBox and
behavioral command names, captions, events, enabled-state rules, and keyboard
order. Each GroupBox now owns one Designer-declared `flpBrowseCommands` with
Add, Refresh, Edit, and Delete in that order. The footer stacks result status
over the actions row, and each button has an explicit logical minimum instead
of inheriting its former full-group width.

The maximum-content injector no longer selects an invented entry in
stable-key-bound DropDownList controls. It retains their real loaded choice and
still exercises long editable text. The geometry runner now rejects any
visible command whose bounds escape a named command bar; this new assertion
caught and closed an initial 200% false pass caused by the old button widths.

Focused fresh-process cells passed for all four forms at 800×552 with maximum
content at relative scales 1.00 and 2.00. All four commands remained inside
their flow container in every cell. The governed control-name exception grows
by exactly four FlowLayoutPanels, with no baseline control removal.

The full four-size/four-scale/ordinary-and-maximum browser atlas, native DPI,
keyboard, High Contrast, and assistive-technology observations remain open.
This is source-side Alpha 5 preparation: no release identity, package, tag,
publication, feed, or protected branch changes here.
