## Manual and operating-system evidence

All workflow, keyboard/accessibility, DPI, settings-profile, interrupted-save,
Windows XP SP3 x86, and Windows 7 SP1 x64 checks are reset to **Not run** for this
new identity. Historical 1.2.1 results and package hashes cannot satisfy them.

## Package evidence

Package filenames, sizes, SHA-256 values, reproducibility comparison, workflow
URL, release URL, and post-download verification will be recorded only after the
candidate source commit is frozen and rebuilt.

## Publication gate

Do not publish or promote the alpha feed while this record is blocked. An alpha
may explicitly retain incomplete future 2.0 features, but it may not retain a
known data-loss path, misleading compatibility claim, mismatched identity, or
unverified package.
