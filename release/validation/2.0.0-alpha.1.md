## Qualification and promotion gate

Alpha 1 has passed its machine-verifiable unpublished checkpoint gate. Before the
tag, exact E must be rebuilt and reproduce the package identities above, then
`build/validate-release-contract.ps1 -Mode Candidate -ExpectedCommit <E>
-RequireArtifacts` must pass through its create-only SHA-bound candidate ref while
`dev` remains at C. Promotion must atomically fast-forward `master` and `dev` to
exact E, create the absent annotated `v2.0.0-alpha.1` tag, and consume that ref.

No GitHub release is created and no Alpha, Beta, stable, or legacy feed is
promoted. Direct child P will then record the observed annotated-tag object and
the factual `tagged / intentionally-unpublished / unpublished /
not-applicable / feed false` outcome. Alpha 2 identity cannot begin until exact P
is validated and present on both permanent 2.x refs.
