# C3 1.3.0 Alpha 5 Deck New structure — 6 August 2026

Result: **PASS for Deck New structure and focused adaptation.**

The original dense Deck editor groups and every behavioral control are
preserved. Their absolute internal geometry now belongs to a fixed preferred
canvas (`pnlDeckCanvas`) inside the dedicated auto-scrolling
`pnlDeckViewport`; the form itself no longer scrolls. A root table reserves the
remaining row for persistent catalogue-status text and a Designer-owned
Add Deck/Cancel command flow.

The form is sizable with a practical minimum. Add and Cancel retain their
default/cancel results, handlers, captions, mnemonics, and accessibility text.
Accessibility declarations and layout settings formerly repeated in Load are
now visible in the Designer; Load only establishes data-dependent defaults.

Direct characterization closes the exact hierarchy, all eight original group
parents, viewport/canvas scroll contract, command parentage, and absence of
runtime AutoScroll/MinimumSize mutation. Five reviewed container names extend
the Alpha 5 allow-list with zero baseline removals.

Fresh-process 800×552 maximum-content cells passed at relative scales 1.00 and
2.00. At 200%, canvas overflow is owned by the viewport while both commands
remain outside it and reachable. The current layout source-policy inventory is
zero in Qualification mode.

Deck Edit, the full Deck New/Edit atlas, and native DPI/keyboard/High Contrast/
assistive-technology review remain open. No release identity, package, tag,
publication, feed, or protected branch changed.
