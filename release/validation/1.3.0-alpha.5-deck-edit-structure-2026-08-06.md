# C3 1.3.0 Alpha 5 Deck Edit structure — 6 August 2026

Result: **PASS for Deck Edit structure and focused adaptation.**

Deck Edit now matches the proven dense-form hierarchy used by Deck New. Its
eight original editor groups remain intact on a fixed preferred canvas inside
a dedicated auto-scrolling viewport. The form itself does not scroll. Status,
Update Deck, and the new explicit Cancel result remain visible in a persistent
Designer-owned command row outside the viewport.

Update keeps its original event handler and persistence semantics. The form
now declares Update as its default command and Cancel as its cancel command;
both have stable mnemonics and accessibility text. Edit loading reads values
from the supplied `deckRow` directly while retaining the corresponding global
table index for the existing update path.

The layout harness gained an explicit System.Data reference and creates a
complete valid representative Deck row before showing this edit form. A forced
Rebuild is required before evidence, preventing stale test output from hiding
fixture compile failures. Six reviewed control names extend the Alpha 5
allow-list, including the previously missing Cancel button, with zero baseline
removals.

Fresh-process 800×552 maximum-content cells passed at relative scales 1.00 and
2.00 through the actual Deck Edit Load handler. Canvas overflow belongs to the
viewport and both commands remain outside it and reachable.

The full Deck New/Edit atlas and native DPI/keyboard/High Contrast/assistive-
technology review remain open. No release identity, package, tag, publication,
feed, or protected branch changed.
