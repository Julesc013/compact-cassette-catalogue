# C3 1.3.0 Alpha 5 static dialog commands — 6 August 2026

Result: **PASS for the first bounded Designer-ownership slice.**

`frmBrandNew` and `frmDeckNew` now declare `btnCancel` in their Designer files.
Each form owns exactly one Cancel command with `DialogResult.Cancel`, a closed
`CancelButton` assignment, a closed `AcceptButton` assignment to the existing
Add command, a CenterParent start position, mnemonic, accessible name, and
accessible description. Their behavior files no longer call
`CatalogueUx.AddCancelButton` or hold a runtime Button field.

This commit deliberately does not claim the later table/viewport/command-bar
layout. Existing final Alpha 4 positions and anchors remain represented so
control ownership can be reviewed separately from adaptive reconstruction.

## Genome control

`build/alpha5-control-name-allowlist.json`. The new
`build/validate-alpha5-control-names.ps1` proves:

- no baseline control was removed or renamed;
- every added Designer field matches an exact path/name/type entry;
- every allow-list entry exists in the current source; and
- each entry carries a review reason.

The preparation gate runs this closure after the baseline-genome comparison.
The initial exact additions are the two `btnCancel As Button` declarations.
