## Publication transaction

Immediately before publication, the remote development branch was re-read as
`11da71e0cc2437e471098c5edb56c24fe72c10e7` and the remote Alpha tag was absent.
The branch and tag were then pushed in one atomic transaction protected by an
exact `--force-with-lease` expectation for that branch. This made the operation
fail closed if either precondition changed.

After the push, `git ls-remote` re-read all four identities in the table above.
The development ref and peeled tag matched the qualified evidence commit, the
annotated tag object matched the local object, and the stable legacy ref was
unchanged.

- the root `VERSION` feed remains exactly `1.2.0 / Release / 14/05/2026`;
- `legacy/1.x` was not advanced; and
