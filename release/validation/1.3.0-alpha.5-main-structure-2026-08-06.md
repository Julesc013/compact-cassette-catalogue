# C3 1.3.0 Alpha 5 Main structure — 6 August 2026

Result: **PASS for the Main Stage A structural hierarchy.**

The original controls and GroupBoxes now have explicit Designer-owned layout
parents:

```text
tlpMainRoot
├── menuStripMain
├── tlpMainHeader
│   ├── tlpMainHeaderLeft
│   │   ├── grpFind
│   │   └── tlpMainIdentification
│   │       ├── grpIdentification
│   │       └── grpScroll
│   └── grpActions
└── pnlMainDataHost
    ├── grpData

    │           ├── tlpEditorMetadata
    │           ├── grpSideA
    │           └── grpSideB

```

The metadata table owns the existing Model, Basic, Taped, and Notes groups.
The two side groups receive equal percentage columns. A preferred-width editor
canvas and `AutoScrollMinSize` keep narrow-window overflow inside the editor
viewport. `frmMain.AutoScroll` is false, and behaviour source no longer calls
`CatalogueUx.ConfigureMainForm`.

One new characterization case closes every parent relationship, the form and
viewport scrolling split, and absence of the runtime Main helper call. The
closed control-name allow-list contains 22 reviewed additions with zero
baseline removals. All 134 characterization cases pass.

The fresh-process Main-only intersection matrix passes 32 cells across four
sizes, four relative font scales, and ordinary/maximum content. Manual review
of the 800×552 Stage A image also shows that the still absolute controls inside
`grpFind` do not all remain reachable at the minimum width. That defect is the
bounded Stage B input; this record therefore makes no Main adaptive, text,
native DPI, accessibility, or Alpha 5 qualification claim.

No release identity, package, tag, publication, feed, or protected branch
changed.
