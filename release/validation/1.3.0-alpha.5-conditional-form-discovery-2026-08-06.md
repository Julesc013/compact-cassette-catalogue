# C3 1.3.0 Alpha 5 conditional-form discovery — 6 August 2026

Result: **REPRODUCED; all five conditional application forms enter bounded
layout reconstruction.**

The first conditional run passed because sibling-intersection checks alone did
not reject children clipped by the form or a non-scrollable parent. The harness
was corrected before classification. It now rejects every named visible control
outside the form or its immediate parent unless a real `AutoScroll` ancestor
makes the control reachable. It also rejects an autosizing label whose measured
text exceeds its client area.

The corrected 160-cell run covers Console, Find Results, Statistics, Settings,
and About at four window sizes, four relative font scales, and ordinary/maximum
