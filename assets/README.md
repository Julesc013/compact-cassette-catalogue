# Assets

This directory keeps non-code material by purpose so contributors can tell
which files are production inputs and which are historical references.

| Directory | Owner and intended use |
| --- | --- |
| `branding/` | Current C3 icons and rendered branding used by the app, README, or releases |
| `design/` | Editable source artwork used to produce branding assets |
| `screenshots/` | Product screenshots used by documentation |
| `reference/` | Historical or visual source material that is not consumed by a build |

Files in `reference/` are archival context, not canonical product
documentation and not release payloads. Confirm origin and redistribution
rights before reusing a reference asset outside this repository.

`reference/legacy-wiki-snapshot.7z` is the pre-overhaul repository wiki
snapshot retained for historical recovery. It is intentionally opaque to the
build and has SHA-256
`5643DAF991F7FB20E9F8CC6B0CFD6A535B8DAC1805191EE6F34A3CAAFDA8FC2A`.
